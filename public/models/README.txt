REKKA 3D RAVEN LOADER
======================
Place the licensed animated raven model here as:

  public/models/raven.glb

The loader automatically searches animation clip names for:
fly / flight / flying / soar / glide / takeoff / wing
and falls back to the model's first embedded animation.

Recommended realistic sources checked 2026-09-28:
1. Realistic Animated Carrion Crow / holylights01 (Sketchfab -> Fab)
   High-detail PBR, LODs, rigged/animated. Obtain under the seller's license.
2. Raven Flying Animated Rigged (Free3D/TurboSquid listing)
   Web-ready GLB variant exists, including an optimized ~8 MB GLB. Paid license.

Do not redistribute marketplace model bytes unless your purchased license allows it.
A model is intentionally NOT bundled here because the realistic animated assets located are marketplace-licensed.
