# REKKA SOFTWARE — Forest Edition

Cinematic React/Vite portfolio for REKKA SOFTWARE.

## Intro
Dark forest → distant torch bearer → raven carrying light → `EVERY IDEA STARTS IN THE DARK.` → REKKA reveal.

The production raven is a lightweight static extraction from the attributed CC-BY source. The original 302 MB morph-cache animation is intentionally not included; motion is choreographed in Three.js for web performance.

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

Railway configuration is included. See `ATTRIBUTION.md` for raven credits.
